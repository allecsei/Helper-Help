# 🛠️ Helper-Help / Helper Menu (B-Zone)

O colecție de scripturi și unelte Lua pentru helperii de pe serverul B-Zone, concepută pentru a ușura activitatea administrativă și suportul acordat jucătorilor.

</div>

## 📌 Despre Proiect
**Helper-Help** este un meniu interactiv creat în MoonLoader (folosind Dear ImGui / MImGui) dedicat helperilor. Include comenzi rapide, ghiduri integrate, status de helper pe datorie și alte funcționalități utile pentru optimizarea timpului pe server.

## 🚀 Instalație și Cerințe

Pentru ca acest script să funcționeze corect, ai nevoie de următoarele dependințe instalate în folderul tău `GTA San Andreas`:
1. **SA-MP 0.3.DL** sau **0.3.7**
2. **MoonLoader** (recomandat v0.26)
3. **CLEO**
4. Librăriile necesare pentru interfață: **Dear ImGui / MImGui** și **inicfg**

---

## ⚙️ Utilizare
Odată intrat în joc pe serverul B-Zone, tastează comanda setată în script sau folosește tasta rapidă dedicată pentru a deschide meniul principal.
